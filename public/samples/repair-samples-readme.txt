Repair PDF manual-use samples

All three PDFs contain a fictional three-page project report.

1. repair-overlapping-text.pdf
Choose Recover readable text, using PDF drawing order. It should create a clean text layout and remove identical text overlays. More output pages are normal: the original dense text is reflowed at a readable size. Images and interactive content are not copied in this mode.

2. repair-clean-reference.pdf
Readable reference containing the same report content in the same source-page order. The recovered layout need not match this design exactly.

3. repair-damaged-structure.pdf
Choose Repair structure. Its startxref offset is deliberately invalid; the page content is intact. Some readers already recover this automatically. Structure repair rewrites references; it does not change text layout.

Rebuild pages preserves visible appearance and does not separate overlapping text. These samples are not malware and do not contain missing content.
