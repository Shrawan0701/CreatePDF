Noto Sans Telugu Regular and Bold are bundled for PDF text shaping and embedding.
The static TrueType files avoid missing glyph outlines seen with the web subset.

Source: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSansTelugu
License: SIL Open Font License 1.1, included in OFL.txt.

Handwriting fonts are bundled locally for consistent previews and PDF exports:

- Caveat Regular: https://github.com/googlefonts/caveat/tree/master/fonts/ttf
  License: caveat-OFL.txt.
- Kalam Regular: https://github.com/google/fonts/tree/main/ofl/kalam
  License: kalam-OFL.txt.
- Patrick Hand Regular: https://github.com/google/fonts/tree/main/ofl/patrickhand
  License: patrickhand-OFL.txt.
